# Relatório de Vendas com Power BI — Desafio DIO

## Sobre o projeto
Projeto desenvolvido para o desafio prático da DIO com foco na construção e documentação de um relatório de vendas no Microsoft Power BI.

O objetivo é aplicar conceitos de análise de dados e visualização, organizar os artefatos do projeto em um repositório GitHub e apresentar o resultado de forma clara para portfólio.

## Objetivos
- Construir e/ou aprimorar um relatório de vendas no Power BI.
- Organizar indicadores e visualizações para facilitar a análise do desempenho comercial.
- Praticar organização visual, filtros e segmentações.
- Documentar o desenvolvimento do projeto.
- Disponibilizar os arquivos e referências utilizados.

## Indicadores sugeridos
- Total de vendas
- Unidades vendidas
- Lucro
- Margem de lucro
- Vendas por produto
- Vendas por segmento
- Vendas por país/região
- Evolução das vendas ao longo do tempo

## Estrutura sugerida do dashboard
### Página 1 — Visão Geral
Cards com os principais KPIs e gráficos para evolução das vendas, produtos e segmentos.

### Página 2 — Análise Detalhada
Detalhamento por produto, país/região, período e segmento, com filtros interativos.

### Página 3 — Lucro e Desempenho
Análise de lucro, margem, produtos de maior contribuição e comparações temporais.

## Tecnologias
- Microsoft Power BI
- Power Query
- DAX
- Git e GitHub
